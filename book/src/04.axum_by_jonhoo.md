# Axum by Jonhoo

## Foundations and ecosystem

Axum is built on top of [Hyper](https://hyper.rs/), which handles the
protocol-level HTTP concerns (parsing requests, writing responses, connection
management, HTTP/1 and HTTP/2 support). Axum itself sits one layer above and
focuses on the web framework experience: routing, handlers, extractors, and so
on.

A defining choice in Axum's design is that it leans heavily on the existing
Rust ecosystem rather than reinventing things internally:

- **Hyper** — all HTTP protocol handling.
- **Tower** — middleware, service composition, timeouts, retries, rate
  limiting, and anything else that fits the `Service` abstraction.
- **Tracing** — structured logging and diagnostics.

This means an Axum app is largely a thin glue layer over crates that are
already battle-tested elsewhere, and skills you learn in one part of the
ecosystem (e.g. Tower middleware) carry over directly.
